# Project GYM 2 — C#

An earlier C#-based gym web application project. The repository currently stores the packaged web project as `GYMWeb.rar`.

## Overview

This project is the C# iteration of the gym management application work in this repository set. It is preserved as a packaged project archive for reference and learning.

## Repository Contents

```text
Project-GYM-2-C-Sharp/
└── GYMWeb.rar    # Packaged C# gym web application
```

## Technology

- C# / .NET web development
- ASP.NET-era web application tooling

> The source is currently stored inside the `.rar` archive, so the exact framework version should be taken from the extracted project files.

## Getting Started

1. Download and extract `GYMWeb.rar`.
2. Open the extracted project in the appropriate Visual Studio version.
3. Restore its NuGet dependencies.
4. Configure the application's database/settings as required by the extracted project.
5. Build and run the web application.

This repository is primarily a historical/project-learning reference for C# web application development and gym-management workflows.
