# Gym Web Solution Packaging Notes

The repository stores the full source project and the deployable archive `GYMWeb.rar`.

## Architecture Details
- **Framework**: ASP.NET Core 8.0 Razor Pages.
- **ORM**: Entity Framework Core with Code-First migrations.
- **Database**: LocalDB / SQL Server Express.
- **Authentication**: Role-based session management across Admin, Employee, and Member portals.
