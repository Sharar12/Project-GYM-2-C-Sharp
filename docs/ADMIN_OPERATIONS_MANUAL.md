# Admin & Front Desk Operations Manual

1. **Member Check-in**:
   - Access `/Action/MemberList` or scan entry barcode.
   - Verify pass expiration badge.
2. **New Signups**:
   - Register member via `/Action/MemberSignUp`.
   - Issue printed receipt via BillingReceiptService.
3. **Trainer Allocation**:
   - Assign coach from `/Action/AssignTrainer`.
