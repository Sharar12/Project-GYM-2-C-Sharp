# Razor Pages Routing & Security Matrix

## Public Pages
- `/Index` - Landing showcase and facility gallery
- `/Privacy` - Membership terms
- `/Action/SignIn` - Unified login entrance

## Member Portal
- `/Action/MemberDashboard` - Personal membership pass & workout stats
- `/Action/MEdit` - Update personal profile

## Staff Portal
- `/Action/EmployeeDashboard` - Trainer shift roster and client assignments
- `/Action/MemberList` - Member directory and check-in confirmation

## Admin Portal
- `/Action/AdminSignIn` - Superuser credentials portal
- `/Admins/Index` - System administrator management
- `/Employees/Index` - Staff hiring and wage configuration
