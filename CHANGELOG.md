# Changelog - Project-GYM-2-C-Sharp

All notable changes to the GYMWeb project are documented in this file.

## [2.1.0] - 2025-03-29
### Added
- Locker rental and management system (`LockerRental`, `LockerManagementService`).
- Billing receipt and invoice generation (`PaymentReceipt`, `BillingReceiptService`).
- Unit test suite for membership expiration, attendance rules, and locker leases.
- Comprehensive technical documentation (System Architecture, ER Diagrams, Routing Guide).
- Standalone deployable release archive `GYMWeb.rar`.

## [2.0.0] - 2025-02-20
### Added
- Employee and Member dashboard portals.
- Attendance logger service with entry validation.
- Trainer dispatch and coaching workload allocation.
- Code-First database migrations (`20250212161314_initial`).

## [1.0.0] - 2025-01-30
### Added
- Core ASP.NET Core Razor Pages solution scaffolding.
- EF Core DbContext and domain models (`Member`, `Employee`, `Admin`).
- Responsive Bootstrap navigation layout and landing pages.
- Authentication pages for Admin, Staff, and Members.
